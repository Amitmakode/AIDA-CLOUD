Concept · Step 01

mkdir — Creating Folders

mkdir foldername creates a new folder inside your current location — the terminal equivalent of right-click → New Folder, just typed instead of clicked.

Naming Matters

  • No spaces ideally — use hyphens or underscores instead
  • Keep names short and descriptive
  • Lowercase is the safest default across all operating systems
terminal
$ mkdir test-folder
$ ls
test-folder/
💡
Real-World Application

Every new project starts the same way for a developer — mkdir the project folder first, then cd into it. This is muscle memory you'll build over the whole course.

Concept · Step 02

cp & mv — Copying & Moving

cp source destination copies a file — the original stays. mv source destination moves it — the original disappears. mv is also how you rename a file.

📄 cp — Copy

📄 → 📄📄
original stays + duplicate appears

📄 mv — Move

📁 📄 → 📄 📁
original gone, only new location remains
CommandOriginal file after?Common use
cp file.txt backup/Still exists in original spotMaking backups
mv file.txt backup/Gone from original spotOrganizing / reorganizing files
mv old.txt new.txtRenamed, not duplicatedRenaming a file
💡
Real-World Application

Data scientists constantly cp raw datasets before cleaning them so the original stays safe, and mv finished scripts into an "archive" or "final" folder once a project wraps up.

Concept · Step 03 · ⚠️ Caution

rm — Deleting Files

rm filename permanently deletes a file. rm -r foldername deletes an entire folder and everything inside it — same permanence, much bigger blast radius.

⚠️
rm = Permanent

Unlike deleting a file in File Explorer/Finder, there is no "Recycle Bin" to recover from. There is no undo, no confirmation prompt by default. Once you hit Enter, it is gone.

Golden rule: double-check your pwd and the filename before running rm — always. Type slowly, read twice, delete once.

💡
Real-World Application

Accidentally deleting the wrong file or folder with rm -r because they were in the wrong directory is one of the most common mistakes even experienced developers make — exactly why professionals run pwd and ls right before any rm.

Concept · Step 05

The PATH Concept

When you type python, your computer searches a specific list of folders to find a program by that name. This list is called the PATH. Installing a tool doesn't always add it to PATH automatically — that's the single most common beginner install issue.

⌨️
Type
python --version
→
Found in PATH?
✅ Yes → Runs the command
❌ No → "command not found"
💡
Real-World Application

This exact error is the #1 reason beginners get stuck on Day 1 of any coding course — once PATH clicks, you'll self-diagnose and fix it instantly instead of panicking.
