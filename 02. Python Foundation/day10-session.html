Concept · Step 01

Variables As Labeled Boxes

A variable is a named container that stores a value. name = "Aditi" reads as "put the value "Aditi" into a box labeled name." Names should be descriptive — age, not x.

"Aditi"

💡
Real-World Application

Every real program — from a simple script to a full data pipeline — constantly stores values in variables: a dataset's file path, a calculated average, a user's name. Without variables, you'd have to retype every value everywhere it's used.

Concept · Step 02

Strings vs Numbers (str, int, float)

Quotes are what decide the type. 25 is a number Python can do math with; "25" is just text that happens to look like a number.

💡
Real-World Application

This distinction is exactly why form inputs, spreadsheet imports, and user-typed data so often cause bugs — a number that looks right can actually be stored as text, silently breaking any math done on it later.

Concept · Step 03

input() — Taking Information From The User

input() pauses your program and waits for the person to type something and press Enter. Whatever they type is returned as a string, always — even a number.

Concept · Step 04

Type Errors — What They Are & Why They Happen

A TypeError happens when two values whose types don't fit together are combined. Classic trap: input() always returns a string — even if the person types 25.

❌ The Error, Live
# user types: 25
$ age = input("Your age: ")
$ print(age + 5)
TypeError: can only concatenate str (not "int") to str
Part of the ErrorWhat It's Telling You
TypeErrorThe types of the two values don't work together this way
can only concatenate str... to strYou can only "add" a string to another string — not a string to a number
💡
Real-World Application

This is one of the most common real-world bugs when working with user input, form data, or files like CSVs — numbers often arrive as text, and forgetting to convert them before doing math is a mistake even experienced developers still make occasionally.

Concept · Step 05

Fixing The Type Error With int()

int() converts a string into a whole number. Fix: age = int(input("Your age: ")) — wraps the input immediately, so age is a real number from the start.

❌ Wrong
# user types: 25
age = input("Your age: ")
print(age + 5)
TypeError
✅ Fixed
# user types: 25
age = int(input("Your age: "))
print(age + 5)
30 ✔
FunctionConverts ToExample
int()Whole numberint("25") → 25
float()Decimal numberfloat("25.5") → 25.5
str()Textstr(25) → "25"
💡
Real-World Application

Converting input immediately, right where you receive it, is a habit professionals build early — it prevents type errors from popping up unpredictably later in a program, far from where the actual mistake originated.

Concept · Step 06

Arithmetic Operators

Python supports all standard math operators, plus two you may not have seen before — floor division (//) and modulo (%), highlighted below.

OperatorNameExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23.5
//Floor Division7 // 23
%Modulo (remainder)7 % 21
**Exponent (power)7 ** 249
💡
/ vs // vs %

/ gives the exact answer, decimals included. // gives just the whole-number part. % gives only the remainder. Together, // and % rebuild the exact same answer / gives you, split into two pieces.

🌍
Real-World Application

% is used constantly — checking even/odd (number % 2 == 0), cycling through options, splitting a total into groups — while // shows up whenever you need a whole-number count, like "how many full boxes of 12 fit into 100 items."
